How to Use This Caching Server

To save bandwidth and speed up updates across your environment, configure your client VMs, LXCs, or servers to route their package requests through this server.

Debian / Ubuntu / Proxmox VE Configuration

Debian-based systems can be configured cleanly by creating a dedicated proxy configuration file. This forces APT to fetch all HTTP packages via the caching server. 

echo 'Acquire::http::Proxy "http://192.168.1.199:3142";' > /etc/apt/apt.conf.d/00aptproxy
apt-get update && apt-get upgrade -y
Note: APT package verification uses cryptographic signatures (`Release.gpg` keys). Routing packages through this proxy is completely secure since package integrity is checked by the client itself.

Alpine Linux Configuration

Alpine Linux uses the APK package manager. To route its downloads through Apt-Cacher NG, configure the `http_proxy` environment variable or edit the default mirrors to use HTTP. 

http_proxy=http://192.168.1.199:3142 apk update && apk upgrade
echo 'export http_proxy=http://192.168.1.199:3142' >> /etc/profile

Rocky / Alma / CentOS Configuration

YUM and DNF use a proxy parameter inside their configurations. 

echo 'proxy=http://192.168.1.199:3142' >> /etc/dnf/dnf.conf
Note: On older installations, edit `/etc/yum.conf` instead.
